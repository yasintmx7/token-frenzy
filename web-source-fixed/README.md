# Token Frenzy - Crypto Slicing Game

A fast, satisfying slicing game where you swipe to slice flying cryptocurrency tokens. Inspired by Fruit Ninja with a crypto twist!

## Project Info

This project is a React-based web game built with modern web technologies.

## Getting Started

To run this project locally, follow these steps:

### Prerequisites

- Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Installation

```sh
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory
cd tokenfrenzy-main

# Step 3: Install dependencies
npm install

# Step 4: Start the development server
npm run dev
```

## Technologies Used

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Deployment

You can deploy this project to any static hosting service like Vercel, Netlify, or GitHub Pages.
